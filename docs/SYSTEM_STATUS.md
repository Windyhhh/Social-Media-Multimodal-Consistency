### 快速开始

1. **启动后端**:
   ```bash
   python app_simple.py
   ```

2. **打开浏览器**:
   访问 http://localhost:5000

3. **登录系统**:
   - 点击"没有账户？注册"创建新账户
   - 或使用已有账户登录

4. **使用功能**:
   - 单个检测
   - 批量检测
   - 查看历史
   - 导出数据
   - 查看性能监控
