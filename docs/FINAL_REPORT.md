## 🚀 部署说明

### 快速启动
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动系统
python app_simple.py

# 3. 打开浏览器
访问 http://localhost:5000
```

### 首次使用
1. 页面加载后显示登录界面
2. 点击"没有账户？注册"创建新账户
3. 使用账户登录进入主系统
4. 开始使用各项功能
